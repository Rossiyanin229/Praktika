# CSharpPracticum

Практикум по C#. Решения 50 заданий, разбитых на 3 уровня сложности.

## Инструкция по запуску

1. Установите .NET SDK (версия 9.0 или выше).
2. Склонируйте репозиторий.
3. Выполните `dotnet run` в корневой папке проекта.

## Статус заданий

| Уровень | Статус | Примечание |
|---------|--------|------------|
| 1 (1–15) | В работе | Задания 1–14 готовы |
| 2 (16–35) | В работе | Задания 16–34 готовы |
| 3 (36–50) | Не начат | — |
